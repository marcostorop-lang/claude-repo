# Dashboard Improvement Plan

**Last updated**: 2026-04-08

---

## 1. Current Dashboard Strengths

- Clean, professional dark-theme design
- Overview with key metrics (PnL, trades, win rate)
- Equity curve visualization
- Daily PnL bar chart
- Strategy comparison with ranking
- Per-market PnL breakdown
- Recent trades table with market names
- Static HTML — no server needed, works via GitHub Pages

---

## 2. Dashboard Gaps

| # | Gap | Severity | Description |
|---|-----|----------|-------------|
| 1 | **Hardcoded config values** | HIGH | Shows "$500 exposure", "10% SL", "15% TP" regardless of actual `.env` config |
| 2 | **No spread-adjusted PnL** | HIGH | Shows raw PnL without accounting for spread cost — creates false confidence |
| 3 | **No open positions view** | HIGH | Only shows trades, not current open positions with unrealized PnL |
| 4 | **PnL calculation independent of backend** | MEDIUM | Dashboard re-derives PnL from trade records; can diverge from actual |
| 5 | **Hardcoded $1000 starting balance** | MEDIUM | `balance: +(1000 + totalPnl).toFixed(2)` — arbitrary |
| 6 | **No exit reason breakdown** | MEDIUM | Can't see SL vs TP vs strategy exits |
| 7 | **No risk utilization view** | MEDIUM | Can't see how much of exposure budget is being used |
| 8 | **No market filter funnel** | LOW | Can't see how many markets were scanned vs filtered vs traded |
| 9 | **No time-series of trades** | LOW | Only latest 30 trades shown |
| 10 | **No category breakdown** | LOW | Can't see PnL by market category |

---

## 3. Misleading Views

- **"Bot Active" with green dot** — always shows active, even if bot is stopped
- **Win Rate** — based on completed trade pairs, doesn't account for open losing positions
- **"Simulated Balance"** — starts at $1000, not derived from actual paper balance
- **Config section** — hardcoded values don't reflect running config
- **PnL** — overstated because paper fills assume midpoint with no spread cost

---

## 4. Required New Metrics

### Must-Have
- Open positions with current price and unrealized PnL
- Exit reason breakdown (SL / TP / strategy / other)
- Spread-adjusted PnL (deducting estimated spread cost)
- Current exposure utilization (% of MAX_TOTAL_EXPOSURE)
- Risk rejection count and reasons

### Should-Have
- Filter funnel: markets scanned → filtered → evaluated → traded
- PnL by category (if category data is available)
- Signal confidence vs outcome correlation
- Hold time distribution
- Time since last trade / last tick

### Nice-to-Have
- Per-strategy equity curve overlay
- Drawdown chart
- Rolling win rate chart
- Market calendar (upcoming resolutions)

---

## 5. Recommended UI/Visibility Improvements

1. **Config section**: Read actual config from a JSON file generated by the bot each tick
2. **Bot status**: Show last tick timestamp; "Active" only if last tick < 2x poll interval
3. **Open positions panel**: Show current positions with live unrealized PnL
4. **Risk dashboard**: Show exposure bars, position count, SL/TP trigger proximity
5. **Filter funnel**: Visual showing how many markets flow through each filter stage
6. **Spread cost overlay**: Show PnL both raw and spread-adjusted
7. **Auto-refresh**: Add meta refresh or simple JS polling for the static HTML
